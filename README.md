Termux (Android) :
1. Installer Termux depuis F-Droid :
   https://f-droid.org/packages/com.termux

3. Dans Termux :
   pkg update && pkg upgrade -y
   
   pkg install python git -y
   
   pip install pycryptodome
   
   git clone https://github.com/maxouxo0/Blackcat
   
   cd Blackcat

5. Lancer le client :
   python client.py

----------------------

Windows/Linux/Mac :
1. Installer Python :
   https://python.org/downloads

2. Dans un terminal :
   pip install pycryptodome
   
   git clone https://github.com/maxouxo0/Blackcat
   
   cd Blackcat

4. Lancer le client :
   python client.py

----------------------

Dans les deux cas :
- Entrer l'IP du serveur quand demandé
- Entrer l'UID du groupe
- 1 pour rejoindre un canal existant
- 2 pour créer un nouveau canal
